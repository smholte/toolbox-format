This browser cannot do it

This browser cannot give a page a folder. Open this page in Chrome or Edge on a PC.

1Connect the Toolbox folder

  1. Press Pick the Toolbox folder.
  2. In the window that opens, go to your own user folder: C:\Users\<your name>.
  3. The first time: make a new folder there named Toolbox.
  4. Click the Toolbox folder once and press Select Folder.
  5. Chrome asks whether this site may edit files. Choose Edit files – and Allow on every visit when Chrome offers it.
